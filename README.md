# SmartPath AI - Study Planner Platform

SmartPath AI Study Planner is an intelligent, full-stack productivity ecosystem designed to automate academic scheduling and optimize learning workflows. By leveraging advanced Large Language Model (LLM) orchestration alongside a robust MVC architecture, the platform transforms a student's chaotic syllabus, documents, and deadlines into a balanced, personalized study roadmap complete with automated revision tools.

## 🚀 Key Features

* **AI Roadmap Generation:** Automatically breaks down dense academic syllabi and project requirements into logical, step-by-step daily study pathways.
* **Document Chatbot & Processing:** Allows students to upload study materials and interact directly with their documents via an intelligent context-aware chat interface.
* **Automated Study Tools:** Dynamically generates custom flashcards and conceptual quizzes straight from course documents to boost active recall.
* **Dynamic MindMap Visualizer:** Formulates structured visual outlines of complex academic subjects to help users grasp relationships between topics.
* **Interactive Productivity Dashboard:** Equipped with a clean interface to monitor milestone completions, manage deadlines, and track overall study progress.

## 🛠️ Tech Stack & Architecture

* **Frontend Framework:** React.js, Vite, Tailwind CSS (Responsive state-driven UI & interactive calendars)
* **Backend Architecture:** Node.js, Express.js (Modular Model-View-Controller pattern)
* **AI & Document Orchestration:** LLM Integration API (For dynamic text analysis, roadmap construction, and study aid generation)
